# Contributing

Thanks for helping improve Bangla Reminder Parser.

## Good issue reports

Please include:

- The input text.
- The expected output.
- Whether the phrase is Bangla, Banglish, English, or mixed.
- Any regional wording that matters.

## Development

```sh
npm install
npm test
```

## Pull requests

Keep changes focused. Add tests for new date, time, or cleanup behavior.
